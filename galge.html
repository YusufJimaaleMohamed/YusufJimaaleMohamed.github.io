Galgje

Een JavaScript woordspel waarbij de speler het juiste woord moet raden.

Over het project

Voor dit project heb ik een Galgje-spel gemaakt met HTML, CSS en JavaScript. De speler moet letters raden totdat het woord compleet is. Bij elke verkeerde letter verlies je een kans.
